HAPPY BIRTHDAY WEBSITE — QUICK GUIDE
======================================

HOW TO OPEN IT
  Just double-click "index.html" — it opens in any browser, no install needed.
  To send it to your mom, upload this whole folder to a free host like
  Netlify Drop (netlify.com/drop) or GitHub Pages, and share the link.

HOW TO CUSTOMIZE

1. Photos
   Your 5 photos are already placed in the "images" folder (mom1.jpg – mom5.jpg).
   To swap any photo, just replace the file — keep the same file name.
   To change captions, open "script.js" and edit the "caption" text inside CONFIG.

2. The song
   Open "script.js" and find CONFIG.youtubeUrl near the top.
   Paste any YouTube link there (youtu.be/... or youtube.com/watch?v=...).

3. The main message (shown after clicking "Open Your Gift")
   Open "index.html", search for "EDIT YOUR MESSAGE HERE" — the text right
   below that comment is what appears. It's already filled in with your message.

4. The closing message (bottom of the page)
   Also in "index.html", search for "EDIT: closing message".

5. Her name
   Open "script.js" and change CONFIG.motherName from "Mom" to her name —
   it will automatically update everywhere the page says "Mom".

That's it — everything else (animations, colors, layout) works automatically.

Enjoy — happy birthday to her! ❤️
